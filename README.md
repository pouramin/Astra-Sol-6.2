# TunnelLab — Astra 6 / Astra 6.2 / Sol 6.2

Bilingual (English-first / Persian) visual experiment website.

## Media publishing — no command line required

The public page is served at https://pouramin.dev/Astra-Sol-6.2/. This project provides the comparison code and the video media through a public CDN.

1. Download and extract Astra-Sol-6.2-media.zip supplied in the ChatGPT conversation.
2. Open the media folder in this GitHub repository. Click Add file → Upload files, and upload all nine MP4 files from the package media folder. Commit the upload.
3. Open the assets folder in this repository. Click Add file → Upload files, and upload all nine JPG files from the package assets folder. Commit the upload.
4. Refresh https://pouramin.dev/Astra-Sol-6.2/ after the CDN has updated. Playback will use the uploaded files automatically.

All videos are below GitHub's 25 MB per-file browser upload limit.
